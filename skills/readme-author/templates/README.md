# README Templates

Use these templates when standardizing repository `README.md` files under the Tanaab README rules.

## Available Templates

- `readme-full/README.md`: use when the repository can keep all durable user-facing documentation in one README.
- `readme-companion-guides/README.md`: use with its `ADVANCED.md` and optional renameable `topic-guide.md` when one or two root-level references keep the common path focused.
- `readme-github-action/README.md`: use when the repository's primary artifact is a GitHub Action and the README must carry the action contract.
- `readme-docs-wrapper/README.md`: use when the README should stay lightweight and delegate durable docs to a VitePress docs site.

For the decision rule, section expectations, and shared `Contributors` embed standard, see [`../../../references/readme-standards.md`](../../../references/readme-standards.md).

When adapting examples, prefer short language-appropriate comments immediately above the commands they explain. Keep surrounding prose for context that cannot fit clearly in a comment.
